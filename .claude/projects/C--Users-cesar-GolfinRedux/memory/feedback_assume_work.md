When user says "check Task.md" or similar, assume they want the tasks executed — don't just summarize and ask.

**Why:** User explicitly said "always assume I want you to work on them except if I say otherwise first."

**How to apply:** After reading any task file, immediately start working on it. Only pause to ask if the task is genuinely ambiguous or has multiple conflicting tasks that need prioritization.
