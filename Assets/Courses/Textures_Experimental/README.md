## Swap-in (manual, Cesar)

1. Pick one TerrainLayer, e.g. `Assets/Golf/Courses/lomond-country-club/Data/hole-01-flat/TerrainLayer_T_Fairway_Light.asset`.
2. Open in Inspector. Set its Diffuse texture to the matching file in this folder.
3. Test on hole 01 only. If the look is good, batch-apply via a separate spec.

## Swap-back

Delete this folder. Original `Textures_2025(JPG)/` is untouched and TerrainLayer GUIDs still point there.

## Notes

- Albedo files are JPG quality 92, normals JPG quality 95.
- Mask maps are NOT regenerated. The existing 4×4 A=0 mask maps continue to apply (TerrainLit smoothness comes from mask map alpha = 0, so JPG albedos are safe — see `Docs/AI_CONTEXT.md` "JPG alpha=1.0" note).
- Light/Dark/BunkerDark/TeeDark variants are brightness-adjusted in this script (see `manifest.json`).
- Resolutions: 1024 for camera-close surfaces, 512 for OOB and asphalt.
