## Current Task — Re-Add Tee Border Ring, Inside-Inset, Small

Tee skirt is done and looks great. Now re-introduce the dark tee border
band — but this time as an **inside-inset ring**, sitting ON TOP of the
flat tee pad rather than extending outward onto the skirt. That way
the ring rides the same flat plane as the tee surface and can't
Z-fight or warp when the skirt slopes downhill.

**Pattern:** CDT the original tee polygon. Use a contour INSET inward
by `borderWidth` as an internal CDT constraint. Triangles inside the
inset contour → tee submesh (playable surface). Triangles in the ring
between inset and original → border submesh (dark band).


**This is the OPPOSITE of the fairway/green fringe pattern.** Fairway
dilates OUTWARD and lets the fringe spill onto surrounding terrain.
Tee insets INWARD and keeps the ring on the flat pad. Both produce
visible border bands; the inset variant is the right choice for tees
because the surrounding terrain is a sloped skirt, not a flat fringe.

```csharp
/// <summary>
/// Flat tee mesh with dark border ring baked in as a second submesh,
/// using an INSIDE-INSET constraint (ring sits ON TOP of the flat tee
/// pad, not extending outward onto the sloped skirt).
///
/// CDT the original contour. An inward-inset contour is passed as an
/// internal CDT constraint so triangle edges land exactly along it.
/// Triangles whose centroid is inside the inset → tee submesh.
/// Triangles whose centroid is in the ring between inset and original
/// → border submesh with distance-based UVs.
///
/// Shared geometry means zero Z-fighting between tee and border. The
/// whole mesh is flattened to a single platformY since the terrain
/// underneath has been raised to a uniform height by
/// FlattenTerrainUnderTees.
/// </summary>
private static GameObject CreateTeeMeshWithInsetBorder(
    int id, ContourPoint[] contour,
    Terrain terrain, float terrainBaseY,
    Material mat, float tileSize,
    Material borderMat, float borderWidth, float borderTileSize,
    Golfin.Course.SurfaceType surfaceType)
{
    int nc = contour.Length;
    if (nc < 3) return null;

    float yOffset = 0.001f; // same tiny lift as CreateTeeMeshFlat

    System.Func<float, float, Vector2> uvFunc = (wx, wz) =>
        new Vector2(wx / tileSize, wz / tileSize);

    // Inset the contour inward by borderWidth. DilateContour with a
    // NEGATIVE offset does edge-perpendicular inward inset (same
    // helper MarkContourCells uses for its `inset` parameter).
    ContourPoint[] insetContour = DilateContour(contour, -borderWidth);

    // CDT the ORIGINAL contour (outer boundary of the whole mesh);
    // pass the INSET contour as an internal constraint so edges
    // land along the tee/border boundary without jaggies.
    var (rawVerts, uvs, tris) = CDTTriangulate(
        contour, terrain, terrainBaseY, yOffset, 1.0f, uvFunc,
        innerConstraint: insetContour);

    bool borderEnabled = rawVerts != null && tris != null && tris.Length >= 3;
    if (!borderEnabled)
    {
        // Fallback: no border, plain flat tee.
        Debug.LogWarning($"[HoleGeoImporter] Tee {id}: inset CDT failed, fallback to borderless");
        (rawVerts, uvs, tris) = CDTTriangulate(
            contour, terrain, terrainBaseY, yOffset, 1.0f, uvFunc);
        if (rawVerts == null || tris == null || tris.Length < 3)
            return null;
    }

    // Platform Y = max of sampled verts (same as CreateTeeMeshFlat).
    float platformY = float.MinValue;
    for (int i = 0; i < rawVerts.Length; i++)
        if (rawVerts[i].y > platformY) platformY = rawVerts[i].y;

    // Flatten everything to platformY.
    for (int i = 0; i < rawVerts.Length; i++)
        rawVerts[i].y = platformY;

    // Centroid for GO position
    float cx = 0f, cz = 0f;
    for (int i = 0; i < rawVerts.Length; i++)
    { cx += rawVerts[i].x; cz += rawVerts[i].z; }
    cx /= rawVerts.Length; cz /= rawVerts.Length;
    Vector3 centroid = new Vector3(cx, 0f, cz);

    // Winding check — ensure top faces up.
    if (tris.Length >= 3)
    {
        Vector3 a = rawVerts[tris[0]];
        Vector3 b = rawVerts[tris[1]];
        Vector3 c = rawVerts[tris[2]];
        float cross = (b.x - a.x) * (c.z - a.z) - (b.z - a.z) * (c.x - a.x);
        if (cross > 0)
        {
            for (int t = 0; t < tris.Length; t += 3)
            { int tmp = tris[t]; tris[t] = tris[t + 2]; tris[t + 2] = tmp; }
        }
    }

    // Classify triangles by centroid relative to the INSET contour.
    // Triangles inside inset → tee submesh (playable surface).
    // Triangles outside inset but still inside original → border submesh.
    // (Triangles outside the original can't exist — we CDT'd the
    // original as the outer boundary.)
    var insetPoly = new Vector2[insetContour.Length];
    for (int i = 0; i < insetContour.Length; i++)
        insetPoly[i] = new Vector2(insetContour[i].x, insetContour[i].z);

    var originalPoly = new Vector2[nc];
    for (int i = 0; i < nc; i++)
        originalPoly[i] = new Vector2(contour[i].x, contour[i].z);

    var teeTris = new System.Collections.Generic.List<int>();
    var borderSrcTris = new System.Collections.Generic.List<int>();
    for (int t = 0; t < tris.Length; t += 3)
    {
        Vector3 va = rawVerts[tris[t]];
        Vector3 vb = rawVerts[tris[t + 1]];
        Vector3 vc = rawVerts[tris[t + 2]];
        float triCx = (va.x + vb.x + vc.x) / 3f;
        float triCz = (va.z + vb.z + vc.z) / 3f;
        bool insideInset = borderEnabled
            ? IsInsideContour(triCx, triCz, insetPoly)
            : true;
        if (insideInset)
        { teeTris.Add(tris[t]); teeTris.Add(tris[t + 1]); teeTris.Add(tris[t + 2]); }
        else
        { borderSrcTris.Add(tris[t]); borderSrcTris.Add(tris[t + 1]); borderSrcTris.Add(tris[t + 2]); }
    }

    // Duplicate border verts with distance-based UVs.
    // U = 1 at tee/border boundary (inset edge), U = 0 at tee outer edge
    //   — so the dark side of the border texture faces outward.
    //   (If the border texture is the opposite orientation, swap to
    //   `u = dist/borderWidth`.)
    // V tiles along world XZ for perimeter variety.
    var finalVerts = new System.Collections.Generic.List<Vector3>(rawVerts);
    var finalUVs = new System.Collections.Generic.List<Vector2>(uvs);
    var vertRemap = new System.Collections.Generic.Dictionary<int, int>();
    var borderTris = new System.Collections.Generic.List<int>(borderSrcTris.Count);
    foreach (int origIdx in borderSrcTris)
    {
        if (!vertRemap.TryGetValue(origIdx, out int newIdx))
        {
            Vector3 src = rawVerts[origIdx];
            // Distance from this vert to the INSET contour (the
            // tee/border boundary). 0 at boundary, borderWidth at
            // the outer tee polygon edge.
            float dist = Mathf.Sqrt(DistanceSqToContour(src.x, src.z, insetPoly));
            float u = 1f - Mathf.Clamp01(dist / borderWidth);
            float v = (src.x + src.z) / borderTileSize;
            newIdx = finalVerts.Count;
            finalVerts.Add(src);
            finalUVs.Add(new Vector2(u, v));
            vertRemap[origIdx] = newIdx;
        }
        borderTris.Add(newIdx);
    }

    var vertsArr = finalVerts.ToArray();
    for (int i = 0; i < vertsArr.Length; i++) vertsArr[i] -= centroid;

    var mesh = new Mesh();
    mesh.name = $"Tee_{id}";
    mesh.vertices = vertsArr;
    mesh.uv = finalUVs.ToArray();
    mesh.subMeshCount = borderEnabled ? 2 : 1;
    mesh.SetTriangles(teeTris.ToArray(), 0);
    if (borderEnabled)
        mesh.SetTriangles(borderTris.ToArray(), 1);
    mesh.RecalculateNormals();
    mesh.RecalculateBounds();

    var go = new GameObject($"Tee_{id}");
    go.transform.position = centroid;
    go.AddComponent<MeshFilter>().sharedMesh = mesh;
    var mr = go.AddComponent<MeshRenderer>();
    mr.sharedMaterials = borderEnabled
        ? new Material[] { mat, borderMat }
        : new Material[] { mat };

    AddCleanMeshCollider(go, mesh);

    var marker = go.AddComponent<Golfin.Course.SurfaceMarker>();
    marker.surfaceType = surfaceType;

    return go;
}
```

### Design note

The green collar (`CreateGreenMeshCDT`) uses OUTWARD dilation, same as
the fairway fringe. That's the correct pattern for those surfaces
because the collar needs to extend onto the surrounding cut terrain
at ground level. For tees, the analogous thing is wrong because the
terrain beyond the tee polygon is the sloped skirt — a collar there
would tilt and warp.

Inside-inset keeps the ring on the flat tee platform, where it stays
planar and renders cleanly regardless of skirt steepness. This is
also closer to how a real tee box looks — the dark perimeter mow band
is part of the flat pad, not extending onto the surrounding grade.
