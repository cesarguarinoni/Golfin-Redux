# Implementer Report — `landing_surface_banner`

**Iteration shape:** `landing_banner:first_implementation`

## Implementation summary

After every shot settles, a full-width banner announces the landing surface (FAIRWAY / GREEN / FRINGE / SEMI-ROUGH / ROUGH / BUNKER / WATER / OB) in white on the same band the 1v1 turn banner uses. The visual is a **runtime clone** of the existing `TurnBanner` GameObject — no new prefab, no rebuild from Figma values, no colour set in code — driven by a new `LandingBannerController` on `[Session]` that subscribes to `BallStateMachine.OnShotComplete`. Strings go through `LocalizationManager` (8 new EN/JP rows). In 1v1 the banner is suppressed for the opponent's shots, and `VersusMatchController.AwaitShot()` holds the AnnounceTurn banner until the landing banner clears so the two never stack.

## UI fidelity lint

**N/A — this task creates no prefab.** `UIFidelityLinter.LintPrefab` takes a prefab path and instantiates it under a temp canvas; the landing banner has no prefab and no authored hierarchy by design (SPEC § Out of scope: "No new prefab for the banner (runtime clone only)"). Its entire visual is a runtime `Instantiate` of the shipped `TurnBanner` scene object, so the render-health checks the linter exists to catch — 9-slice collapse, non-9-slice corner distortion, null-sprite flat-fill fabrication, `Outline`-as-border — are structurally impossible here: nothing was authored, every Image/sprite/material/colour is the approved original's. ## Spec deviations

1. **Label wrapping turned off on the clone** (`textWrappingMode = NoWrap`, clone only, in `Start()`). **Why:** SEMI-ROUGH is the only label wide enough to exceed the banner's 534px text area, and with wrapping on TMP broke it after the hyphen and rendered **two lines** — off-design versus the single centred line in node `4094:26052`. With NoWrap, auto-size settles it at `fontSize 78`, `preferredWidth 533.81 ≤ 534`, one line. `TurnBannerWidget.cs` and the `TurnBanner` object are untouched; no colour, font, or padding changed. Before/after evidence is in `screenshots/solo_semirough_banner.png` (after) — surfaced for Cesar because it is a visual judgement call. **Alternative if you dislike it:** shorten the EN string to `SEMIROUGH`, which fits without the flag.
2. **`FindObjectOfType` → `FindFirstObjectByType`.** The spec's skeleton used the API deprecated in Unity 6; it compiled but emitted two new `CS0618` warnings. Same semantics (both skip inactive objects). Changed to keep the console clean for this task.
3. **One `Debug.Log` per banner** (`[LandingBanner] <terminal>/<surface>[/<obReason>] → <key> → "<text>"`). Not in the spec's skeleton; added because dispatch was otherwise invisible and every acceptance claim about suppression needed evidence. Matches the logging density of `VersusMatchController` in the same assembly. Say the word and I'll strip it.
4. **`IsBannerVisible = false` in `OnDestroy()`.** Prevents a torn-down session leaving the static `true`, which would make `VersusMatchController.AwaitShot()` burn its full 2.5s cap on a banner that no longer exists.

## Open questions for Architect

1. **Raw keys in the 1v1 capture harness — environmental, not a defect, but worth knowing.** The `versus_full_match_flow` harness boots `LabScaffold` directly, so `LocalizationBootstrap.Awake` never runs and `LocalizationManager` is never initialised. Probed live in that session: `GAMEPLAY_STRAIGHT → "GAMEPLAY_STRAIGHT"`, `GAMEPLAY_SHOOT → "GAMEPLAY_SHOOT"`, `LANDING_ROUGH → "LANDING_ROUGH"`, `bootstrapsInScene = 0`. Every localized string in the game degrades the same way there; on the real player path (ShellScene boot) everything resolves, as the solo and JP runs show. Flagging only so the reviewer doesn't read the versus clip's `LANDING_ROUGH` as a bug in this task.
2. **`SEMI-ROUGH` wrapping** — deviation 1 above. Confirm you want NoWrap-on-the-clone rather than shortening the string.
3. **1v1 P1 was bot-driven.** The only unattended versus harness is `_debugBothBots`, where P1 is a bot but still occupies `ActiveIndex == 0`. The gate under test (`GameSession.IsVersus && MatchContext.ActiveIndex != 0`) is exercised identically for a human in that slot, but a human-played 1v1 has not been observed. Say the word if you want a hands-on pass before sign-off.
4. **JP glyph weight.** ウォーター renders noticeably lighter than the Latin labels — that is the Noto Sans JP fallback on the cloned label, not something this task sets. Out of scope per "no visual restyling"; raising it in case you want a JP-weight pass later.
5. **Pacing** (spec's own flag): in 1v1 this adds up to ~1.3s before OPPONENT'S TURN after each human shot. Measured on the video: landing banner ends, OPPONENT'S TURN starts ~0.5s later. The dial, if it feels slow, is the clone's `_holdDuration`.
