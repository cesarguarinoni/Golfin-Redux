# VFX_REDESIGN — `water_splash_fx` Problem B (splash looks bad)

**Author:** Architect (claude.ai) · **Date:** 2026-06-13
**Scope:** Rebuild `Assets/Resources/FX/WaterSplash.prefab` so it reads as a water splash, not an airborne cloud. **Zero gameplay impact stands** — only the prefab + its material + textures change. Controller (`WaterSplashController.cs`), trigger, tests, scene = untouched.

## Root cause of the "cloud"
Current prefab = one soft-alpha sprite, scaled large, long lifetime, no gravity, additive-ish overlap → textbook fog. A splash must be **layered + short + gravity-driven**.

## Assets (Cesar places these — generated by Architect)
Replace `T_WaterDroplet.png` with three new textures in `Assets/Resources/FX/`:
- `T_SplashDroplet.png` (128²) — defined-edge droplet (solid core, tight feather). NOT the old soft blob.
- `T_SplashRing.png` (256²) — flat ripple ring, transparent centre.
- `T_SplashFoam.png` (256²) — lumpy soft splat with solid core.

Import settings (all three): **Alpha Is Transparency = ON, sRGB = ON, Wrap = Clamp, Filter = Bilinear, Max Size = 256, Compression = Normal.**

## Material (one shared)
`WaterSplashParticle.mat` → **URP / Particles / Unlit**, Surface = **Transparent**, Blend = **Alpha** (NOT additive — additive overlap is half the fog problem). Tint white, no emission. Per-layer colour set via Start Color, not the material.

## Prefab structure
Parent `ParticleSystem` (this is what `WaterSplashController` pools + `Clear()`/`Play()`s — propagates to children) with **4 child sub-systems**, all bursting at t=0. Total ≤ ~35 particles (SPEC §3 mobile budget). No Lights module, no Collision module.

| Layer | Texture | Shape / Render mode | Burst | Lifetime | Start speed | Gravity Mod | Start size | Key modules |
|---|---|---|---|---|---|---|---|---|
| **Foam pop** | Foam | Camera billboard, at entry point | 1 | 0.22 s | 0 | 0 | ~0.8 | Size-o-Life 0.4→1.1; Color-o-Life alpha 1→0 (ease-out) |
| **Ripple ring** | Ring | **Horizontal Billboard** (lies flat on water plane) | 1–2 | 0.6 s | 0 | 0 | 0.3 | Size-o-Life 0.3→1.6; alpha 0.9→0 |
| **Jet / crown** | Droplet | Cone pointing **+Y**, angle 18°, **Stretched Billboard** (Length Scale ≈ 2.5, Speed Scale ≈ 0) | 14 | 0.5–0.8 s | 3.5–5 | 1.0 | 0.10–0.18 | vertical spray streaks; alpha 1→0 over life |
| **Scatter droplets** | Droplet | Cone **+Y**, angle 50°, normal Billboard | 18 | 0.5–0.9 s | 2–4 | 1.0 | 0.06–0.12 | flung out, fall under gravity; alpha 1→0 |

## Anti-fog acceptance points (verify each)
1. Every layer lifetime **≤ 0.8 s** (foam/ring/jet/scatter as above).
2. Gravity Modifier **= 1.0** on jet + scatter so droplets *fall* (arc), not float.
3. Material blend = **Alpha**, not Additive.
4. Colour stays **bright white** (optional faint cyan `#DCF2FF` on droplets) — no pale-translucent-blue.
5. Scale tuned to ball (ø ≈ 0.43 m). Absolute scale is Cesar's visual-gate call; ratios above are the design.
6. Particle count ≤ ~35; no Lights, no Collision.
