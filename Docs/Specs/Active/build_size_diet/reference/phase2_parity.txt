== The experiment ==
The SAME code was run against BOTH data formats, by swapping only the bytes under
Assets/Resources/HoleData:

  AFTER  : the converted tree — GHM2 heightmaps + gzip zones.bytes
  BEFORE : `git checkout 5d8bd6f83 -- Assets/Resources/HoleData` (the commit before the
           conversion) — GHM1 heightmaps + pretty zones.json, zones.bytes removed so
           Resources.Load had exactly one candidate
  AFTER  : restored from a byte-for-byte copy taken before the swap, and re-run

That ordering matters: running only "after" would show the suite is green, not that it is
UNCHANGED. And the BEFORE run doubles as proof that the GHM1 / zones.json fallback paths in
HeightmapLoader and HoleDataIO actually work rather than merely being written down.
