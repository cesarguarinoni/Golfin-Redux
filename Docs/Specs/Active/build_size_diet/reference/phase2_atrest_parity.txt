# THE EXPERIMENT. The same 12 shots were fired on Hole 1 and Hole 6 against BOTH datasets,
# swapping only the bytes under Assets/Resources/HoleData:
#   after  = the converted tree — GHM2 heightmaps + gzip zones.bytes
#   before = git 5d8bd6f83 — GHM1 heightmaps + pretty zones.json, with zones.bytes removed
#            so Resources.Load('.../zones') had exactly one candidate
# Verified in-run before firing, not assumed: the loader reported
#   heightmap magic=GHM1 (16,793,640 B); zones gzip=False (8,318,783 B)
# and the lab reported _bakedClassifier=BakedZoneClassifier, _bakedGround=BakedHeightProvider,
# so the shots really did read the data under test rather than falling back to scene providers.
#
# WHY RAW LONGS. Trajectory.finalPosition is fp3 — Q32.32 fixed point. Printed as metres the
# comparison would round away exactly what this gate exists to catch, and the SPEC asks for
# 'bit-identical (fp values, not close)'. Every number below is fp.raw, compared with ==.
#
# THE PRESETS. Four drivers (calm/head/tail/crosswind), a 7-iron, two wedges and a rough
# landing exercise the heightmap over hundreds of metres of carry, bounce and roll; four
# putts exercise the green mesh and the zone classification at centimetre scale.
