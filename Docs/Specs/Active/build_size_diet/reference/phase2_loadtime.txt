# The SPEC asks for hole-load wall time before/after. Measured here as the DECODE
# itself rather than as a hole-load stopwatch, because the decode IS the entire
# delta Phase 2 introduces, and a hole load is seconds of terrain, meshes and
# shaders around it — a 30 ms change would sit inside that measurement's own
# noise and prove nothing either way. The old bytes come straight out of git at
# 5d8bd6f83, so this is the real before, not a reconstruction.
